### Upgrade notes
- Deprecation: `scan -f json` keeps writing report schema 1.0 by default in 0.115.x, and 0.116.0 makes schema 2.0 the default. Opt in now with `--report-format v2` (or `AGENT_BOM_REPORT_FORMAT=v2`); pin 1.0 with `--report-format v1` (alias `legacy`). An interactive `scan -f json -o <file>` prints a one-line notice to stderr; CI jobs, `--log-json`, `-q` and an explicit `--report-format` do not. Schema 2.0 (`contracts/v2/`) carries the same evidence with each compliance control, package, asset and provenance record written once and referenced by ID: `findings[].controls` becomes `findings[].control_refs` into a top-level `compliance_controls` map, package occurrences carry `package_ref`, finding assets `asset_ref`, blast-radius rows `finding_ref`, provenance objects `*_provenance_ref` into `provenance`, and the root `packages` alias and `inventory_snapshot.packages` are omitted. `agent_bom.output.report_packing.expand_report` restores the 1.0 document exactly, and every agent-bom reader (report commands, `--baseline`, `--inventory`, `graph`, `mesh`, `attest`, `findings push`, MCP tools, the dashboard import) accepts either schema.
- `scan --push-url` sends schema 2.0 when the control plane's `GET /version` lists `"2.0"` in the new `report_schema_versions` field, and 1.0 to any other control plane, so a 0.115.0 client works with older control planes and older clients work with a 0.115.0 control plane. `POST /v1/results/push` expands a 2.0 report before validating and storing it: stored results, findings and graphs are the same for either schema. A 2.0 push with a reference that names no record is refused with 422, and one whose references would expand past the 240 MiB storage ceiling with 413.

### Performance
- Scan pushes to a 0.115.0 control plane are about a third smaller with the same evidence (report schema 2.0 on the wire): the compact body for a 10-package project with 176 CVE findings drops from 3.92 MB to 2.65 MB, and for this repository with `--quick` from 14.0 MB to 9.1 MB. `--report-format v2` files shrink the same way (6.26 MB to 4.15 MB and 21.7 MB to 12.9 MB).
