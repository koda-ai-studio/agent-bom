### Added
- Each framework agent now links to the model(s) it uses. LangGraph, CrewAI, AutoGen and OpenAI Agents SDK agents read the model from constructor arguments (`model=`, `llm=`, `model_client=`, `llm_config=`), chat-model wrappers such as `ChatOpenAI(model=...)`, `ChatAnthropic(...)`, `LLM("openai/gpt-4o")` and `init_chat_model("openai:gpt-4o")`, AutoGen `llm_config` / `config_list` dicts, and CrewAI `agents.yaml` entries (#5981). Every `serves_model` edge records the provider and where the model is declared: code or config with file and line. A model chosen by an environment variable records the variable's name only, never its value; with no literal default it links to an `env:<NAME>` model node. The scan reads source and config files only; it never imports or runs them.
