### Fixed
- The public demo builds again. Its sample data had no answer for the Agents page's paged `GET /v1/agents` read, and the recorder then published Agent topology as "in the demo" because an earlier page had already found that read unanswered, so the topology page showed its error state and the docs deploy failed. The sample answers paged and unpaged reads, every page that needs a missing read is left out of the demo, and the demo check now also confirms that each Overview category chip matches the Findings view it opens.
- Agent topology reads one bounded page of agents (500, the API maximum) instead of the whole list, and says how many it shows when the estate is larger.
- The Overview "Secrets" chip shows the number of open secret findings that its link opens. It used to show findings on servers that hold credentials, so the quickstart sample read "Secrets 24" over an empty list. An imported report's chip is named "Credential-exposed", since a report has no secret-findings view to open.
- The Overview "KEV" chip's link now opens only known-exploited findings. Findings ignored the `kev=1` parameter and listed every finding, so the demo's "KEV 0" opened a list of 15. Findings shows the filter and a "Show all findings" button to clear it.
- The Agents page no longer counts a scanned repository, SBOM or image as an agent. `GET /v1/agents` on a scanned estate lists the agents the graph records, so the quickstart sample shows 2 agents on both the Agents page and Asset inventory instead of 3 and 2.
- Agent names with spaces read normally in the Findings reach column and other places that show the end of a graph node ID ("Cursor First-Run Workspace", not "Cursor%20First-Run%20Workspace").
- On a phone, a scope overview of up to 8 scopes stacks them in one column with every card in view at reading size, instead of opening on one card out of six.
- Grouped-map relationship labels keep clear space from each other and from the group cards, and the camera frames them, so a label in a phone's side lane is no longer cut off at the canvas edge.
