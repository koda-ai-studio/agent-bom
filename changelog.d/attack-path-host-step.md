### Changed
- **Attack paths follow a compromised host to what runs on it.** A chain that reaches a compute host (a container workload, or a cloud resource classified as a compute instance) now continues to each agent, MCP server or workload recorded as hosted on it (`hosts`, or `hosted_on` read from the host's side). For example: Internet → exposed workload → the agent it hosts → its MCP server → a credential → customer data. Environments, accounts and clusters also "host" their inventory but are scopes, not hosts, so a chain never steps from one to everything inside it. Fused paths and partitioned campaigns share the same step. The graph data model lists it as its own analysis edge set ("Host compromise").
