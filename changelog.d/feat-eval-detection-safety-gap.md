### Added
- The AI-inventory scan reads eval suites committed with a project (promptfoo configs, deepeval tests, ragas evaluations, Inspect tasks, OpenAI evals, LangSmith datasets) without running them, labels each as safety, quality or unknown only from what its files show, and links it to the agent or model it targets or marks it unlinked. Suites appear as `eval_suite` graph nodes with `evaluates` edges, in `ai_inventory.eval_suites`, in the scan console and in the agent architecture detail panel, with any recorded results labelled by source file and date (#5984).
- A governance finding, `EVAL_COVERAGE_GAP`, flags framework agents with write/exec tools, credentials or data access that no safety or red-team eval is linked to. It is raised only when eval detection searched the agent's project, says what was searched, maps to NIST AI RMF MEASURE-2.6 and MEASURE-2.7, and is kept out of CVE counts and the severity exit gates. Thresholds are in `docs/AI_EVAL_COVERAGE.md` (#5985).
